# Wet-lab template sources

The **New experiment** menu contains editable scheduling scaffolds for common wet-lab work. The steps are deliberately high-level: they capture hand-on work, waiting windows, hand-off points and records that are useful for planning, while leaving concentrations, temperatures, timings, instrument programs and acceptance criteria to the lab's approved SOP.

## Public GitHub references

- [tlnagy/protocols](https://github.com/tlnagy/protocols) - a public collection of wet-lab molecular biology protocols. Its organization informed the separation of sample preparation, reaction, incubation and readout stages.
- [BisanzLab/LabProtocols](https://github.com/BisanzLab/LabProtocols) - a maintained lab protocol repository used as a reference for reusable preparation, extraction and assay hand-offs.
- [buckleylab/Buckley_lab_protocols](https://github.com/buckleylab/Buckley_lab_protocols) - combines wet-lab protocols with sample sheets and analysis hand-offs; this informed the explicit sample registration and raw-file steps.
- [ec363/wet_lab_resources](https://github.com/ec363/wet_lab_resources) - public wet-lab resources covering molecular biology references and calculators; this informed the calculator warning and the separation of planning from validated conditions.
- [Autodesk/bionano-wetLabAccelerator](https://github.com/Autodesk/bionano-wetLabAccelerator) - an open visual protocol-planning project; its task-oriented representation informed the editable, timer-friendly step model.

## Template coverage

The menu now includes a blank workflow plus PCR/qPCR, DNA/RNA extraction, agarose gel electrophoresis, Western blot, ELISA, cell culture passaging, cell transfection, immunofluorescence, flow cytometry staining and sequencing library preparation.

## Curation and safety boundary

These templates are not copied protocols and are not a substitute for training, biosafety review, reagent instructions or an approved SOP. A template should be duplicated and edited with the local sample IDs, reagent lots, equipment, controls, validated durations, acceptance criteria and deviation notes before a run is started. The app records execution state; a completed timer does not certify experimental quality or biological success.
