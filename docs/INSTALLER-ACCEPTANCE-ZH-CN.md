# 时序安装包验证指南

包版本：2.0.0-beta.2。新安装默认显示英文界面与空白工作区；需点击按钮才载入英文植物示例。软件界面名称为“时序 · 科研调度与实验执行”，不含版本后缀。

## 安装包选择

| 系统 | 文件 | 使用方式 |
| --- | --- | --- |
| Windows 10/11，64 位 Intel/AMD | win/Shixu-Desktop-2.0.0-beta.2-win-x64.exe | 运行安装向导，选择用户目录安装 |
| Mac，Apple Silicon（M 系列） | mac/Shixu-Desktop-2.0.0-beta.2-mac-arm64.dmg | 打开镜像，将应用拖至 Applications |
| Mac，Intel | mac/Shixu-Desktop-2.0.0-beta.2-mac-x64.dmg | 打开镜像，将应用拖至 Applications |

mac 目录还提供对应架构 ZIP，供直接解压测试。不要同时运行两个副本。

这是可供内部验证的构建包，版本尚未转为稳定版。Windows 未配置发布者证书；macOS 使用有效 ad-hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。系统可能提示未知发布者或要求批准。请由测试者根据系统正式提示确认；不要关闭系统安全保护。

先在现有应用中导出 JSON 备份。该版本数据目录沿用 Shixu Desktop 2 Beta；如已有记录，启动时显示已有数据是预期行为，不应清空数据以获取示例。

| 检查 | 预期结果 |
| --- | --- |
| 首次安装、启动和再次启动 | 主界面正常，记录持久保存，托盘和悬浮窗可使用 |
| 中英文切换并重启 | 界面、托盘和悬浮窗使用所选语言；用户自行填写的内容不被翻译 |
| 示例项目 | 新数据目录为空；仅点击示例按钮后载入 6 个英文植物课题；重复点击不重复新增 |

| 实验计时 | 使用一条测试实验验证倒计时、重启恢复、到时提示；不要用真实实验作为首次测试 |
| 开机自启动 | 点击后状态与系统启动项一致；注销登录后验证真正启动，再关闭此项确认状态 |
| 备份与恢复 | 导出后在独立测试环境导入，项目、附件引用、实验结果和关联关系保留 |
| 安装升级与卸载 | 使用备份检查旧版本升级，卸载后确认应用移除及数据保留情况 |
