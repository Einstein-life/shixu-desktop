# 2.0 beta 源码使用说明

本次开发全部保存在 `ImproveEfficiency/v2.0`，版本为 **2.0.0-beta.2**。新安装默认英文界面和空白工作区；用户点击后才载入英文植物研究示例。原版 Python 目录、Windows 1.x 目录与 macOS 1.x 目录未改动。

## 启动

在此 v2.0 目录打开终端，准备好 Node.js 20 或更新版本，然后运行：

```text
npm ci
npm run localize
npm start
```

`npm ci` 会安装本目录需要的 Electron 依赖。`npm start` 使用本版本的独立启动器，它会去除 Electron 路径文件末尾的换行。

主窗口顶部的语言菜单可选择 English / 简体中文。悬浮窗和系统托盘使用相同的语言设置。实验员填写的样本名、实验标题、步骤名与结果记录保留原文。

## 推荐试用顺序

1. 打开“实验执行”，新建一个空白实验，输入样本/批次和自定义步骤。
2. 完成准备清单，启动一个短等待步骤，观察倒计时和预计结束。
3. 确认此步完成，再手动启动下一步；计时结束不会自动判定实验成功。
4. 记录结果、偏差和原始文件位置，导出实验 Markdown。
5. 使用“配液计算”输入已确认的浓度和单位；计算器不负责选定实验条件。
6. 切换 English，检查任务、项目、实验、回看、悬浮窗及托盘。
7. 在回看页导出 JSON 备份；导入会询问是否替换，并保留导入前备份。

初次启动会从旧桌面版用户数据文件复制并迁移到 **Shixu Desktop 2 Beta** 独立目录，不会修改旧数据文件。也可手动导入原版导出的 JSON。浏览器预览与旧 Python 本机桥接分开存储，不会向旧桥接接口提交数据。

## 验证与打包

```text
npm test
npm run check
npm run localize
npm run dist:win
```

macOS 使用同一套源码，在 macOS 上安装依赖后运行 `npm run dist:mac`。正式发布前仍需分别完成 Windows 和 macOS 的实际安装/升级、通知、多屏、休眠恢复与数据往返测试。

目前交付的是源码 beta，尚未生成并验证正式 Windows/macOS 安装包。请阅读同目录的验证报告，区分已通过的自动测试和未完成的桌面验收。
