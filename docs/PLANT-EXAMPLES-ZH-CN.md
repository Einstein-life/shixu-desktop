# 内置植物研究示例

示例共 **6 个项目、18 条执行事项和 6 份实验记录**，可载入完整中英文两套；内容和结果均为模拟，不代表真实研究发现，远程文件路径仅为占位。

| 项目 | 分析流程 | 实验与重点记录 |
| --- | --- | --- |
| 拟南芥盐胁迫的转录响应与 qPCR 验证 | Bulk RNA-seq | 候选基因独立验证、qPCR 原始记录与内参稳定性、批次与 contrast、组会图注和局限 |
| 水稻干旱响应的甲基化—表达联合分析 | WGBS / RRBS，包含表达联合步骤 | 匹配样本与坐标、核酸提取送样、CG/CHG/CHH 和覆盖检查、相关性与因果局限 |
| 番茄根际微生物与低磷响应 | 16S / ITS 扩增子 | 根际 DNA 提取、阴性对照、盆栽区组、ASV 与污染筛查、植株磷指标映射 |
| 玉米高温胁迫与花粉活力 | Bulk RNA-seq | 开花期、冠层温度、花粉活力、结实性状与批次核对 |
| 小麦叶锈菌互作与抗性候选基因 | Bulk RNA-seq | 菌株与接种设计、mock 对照、病程评分和宿主/病原 reads 分类 |
| 大豆根瘤共生与根际群落 | 16S / ITS 扩增子 | 菌株身份、盆栽—根瘤—根际映射、氮素条件和阴性对照 |

每个项目均包含研究问题、设计、参考与参数待填信息、可编辑分析步骤、三项里程碑、样本表引用、关联实验、结果记录、局限和下一步行动。执行事项包含分析、湿实验核对、文献、组会和交接示例；其中一项已完成，另一项展示模拟的计算等待状态。

## 载入与使用

- 全新桌面数据目录和全新浏览器工作区首次打开时自动载入，并立即保存一次。
- 已有记录或已主动清空的工作区不会自动补入示例；可在“项目进度 → 载入植物研究示例”添加。
- “项目进度 → 载入英文植物示例”会将玉米、小麦和大豆课题以独立英文记录添加到当前工作区；不会翻译或覆盖已有中文示例。
- 重复载入以稳定记录 ID 去重；已有示例的编辑内容和其他项目不被改写。已经删掉的示例可以通过此按钮重新补回。
- 示例可以直接编辑使用，也可通过已有项目和事项管理入口分别归档或删除。示例计时器不会自动启动；图示时长需按自己的实验室 SOP 修改。
- “项目进度 → 分析与结果”可浏览五段式记录；“实验执行 → 记录结果”可修改关联实验，再回到项目查看最新结果证据。
- 下一步行动已有对应执行事项，可在调度中查看；同一行动已有未完成事项时不会再次生成。
- 首次创建时按当前语言生成中英文示例。切换语言保留已保存的项目内容；也可用英文专用按钮加入英语示例。
- `index.html?demo=1` 使用独立的浏览器存储，编辑可在该演示工作区保留，不读取桌面数据或旧版工作区。

日期随载入当天生成；示例结果、占位文件和预填完成状态用于演示界面，不可作为论文数据或真实实验质控记录。
